# My Book Tracker Family — восстановленный проект

Редактируемая реконструкция приложения по APK версии 1.0.22. Сохранены пакет Android, роли родителя и ребёнка, семейный код, книги, прогресс, XP, серии чтения, тесты, награды, достижения, талисманы и схема Firestore.

## Запуск

```powershell
pnpm install
pnpm start
```

Проект сразу открывается в безопасном демонстрационном режиме. Локальные изменения сохраняются через AsyncStorage.

## Firebase

Скопируйте `.env.example` в `.env` и заполните значениями проекта Firebase. Коллекции оригинальной сборки: `users`, `books`, `rewards`, `progress`, `events`.

Текущая версия намеренно не записывает данные на сервер, пока не будет проверена конфигурация и правила Firestore.
